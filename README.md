# jiayuww.github.io

Personal website of Jiayu (Mila) Wang — a single static page (`index.html` + `style.css`), no build step.

- Edit `index.html` to update bio, news, and publications (copy an `<article class="row pub">` block to add a paper).
- Pushing to `master` publishes the site to the `gh-pages` branch via `.github/workflows/deploy.yml`.
- `SkillOrchestra/` hosts the SkillOrchestra interactive demo at `/SkillOrchestra/`.
- The previous al-folio site is preserved on the `backup/al-folio-source` and `backup/al-folio-site` branches.
